## 从已接受结果提炼的工作流补充

### 不同首帧贴图序列映射至统一时间线起点的表达式写法
适用条件：多个材质或节点读取不同起始帧号的连续四位帧序列（原速播放、范围外保持首末帧），需统一对齐到指定目标起始帧；此方法不控制显隐。

先读取实际磁盘目录确认每个序列的真实首帧 source_start 与末帧 source_end，定位材质暴露的贴图文件参数；在 $HIP 相对路径中将 $F4 替换为 `padzero(4, clamp($F - target + source_start, source_start, source_end))`，保留原有通道引用。修改后逐帧 evalAtFrame 并验证目标帧段内所有解析路径在磁盘上真实存在。

原因与注意：直接使用 $F4 会按全局时间线帧号读取，无法适配起始帧不统一的多组序列贴图。

### 工程保留用户主版本号，追加两位助手迭代序号
适用条件：助手修改并另存 Houdini 工程文件时。

保留用户原有主版本号及完整扩展名（.hip/.hiplc/.hipnc），不擅自升主版本号；在原版本段后追加两位助手迭代序号：例如 v02.hip → v02_01.hip → v02_02.hip。不叠加多层序号，不覆盖已有迭代文件，也不为规范而擅自重命名未修改的工程。

原因与注意：保持用户原有的主版本管理体系清晰不被打乱。

来源：memory=fe600dfe239546a2a74bf2b1952474bd

### 沿路径流动能量带分阶段保留基础粒子与路径变形缓存
适用条件：制作沿指定曲线路径流动、缠绕或分叉的粒子与细丝能量带。

将流程拆分为：路径/发射源缓存 → 基础粒子模拟缓存 → Path Deform（可结合 For-Each 多条曲线）变形缓存。多组不同色彩或层次的能量噪声分支保持各自独立输出和 ROP，不要强行合并为一个渲染层。调整速度时核对路径方向、curveu 范围、时间映射与 Retime 顺序。

原因与注意：先算基础形态再沿路径映射，轨迹可控性强且便于单独微调路径曲线和节奏。

来源：memory=349477b1d0b04bbf869290c728d71de2

### 自建SOP HDA视口正常而ROP写出原始缓存：同时核对Display与Render旗标
适用条件：SOP HDA 或子网在视口中显示正确（如变速/后处理生效），但 File Cache / ROP 写盘读回却仍是未处理的原始输入。

不要只凭视口显示或无报错就判断写盘生效。先对比 live 节点与磁盘缓存的几何类型、体素大小和属性统计；重点查询 HDA 内部的 displayNode 与 renderNode，常见根因是 Display 指向最终 output 节点而 Render 仍留在上游输入节点。将最终输出节点同时设为 Display 与 Render 旗标，保存 HDA 定义和 HIP，再用短帧段实际写盘读回验证与 live 一致后再跑全段缓存。

原因与注意：Houdini ROP/File Cache 默认读取 Render 旗标而非 Display 旗标，旗标分离会导致看似参数/K帧失效。

来源：memory=21f4396142634688af5c5a809eb5c432

### 角色局部粒子效果将模拟与随动变形分阶段缓存
适用条件：粒子效果需要贴附或跟随角色局部动画，且角色输入网格拓扑稳定、参考帧关系明确时。

将解算与随动变形拆成两个独立缓存阶段：第一阶段在相对静止或参考空间完成 POP 模拟并写基础模拟缓存；第二阶段用 Point Deform（三输入分别为模拟点、Timeshift 固定参考帧几何、当前帧动画几何）完成随动变形，再单独写变形后缓存。复用前务必先核对参考帧与当前帧拓扑一致性，避免变形炸点。

原因与注意：分阶段缓存把解算迭代和随动绑定解耦，调整变形或局部动画时无需重算粒子模拟。
