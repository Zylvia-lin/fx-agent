## 从已接受结果提炼的工作流补充

### 曲线驱动造型变形效果优先主曲线+curveu Ramp+VEX精简网络
适用条件：制作沿主引导线推进的卷浪、弧形冲击波、可控丝带等需要艺术化调节的 SOP 造型动画。

使用主引导曲线的位置驱动效果空间随动；沿曲线用 Resample 生成 curveu，将幅度/卷曲度/高度等核心造型参数暴露为独立命名参数，沿线渐变使用可编辑 curveu Ramp 控制（禁止硬编码数组或散落常量）。数学变形与截面计算优先用简洁的 Attribute Wrangle（VEX）完成，只保留必要的控制曲线、重采样、成面等节点，避免冗余堆砌节点。

原因与注意：VEX + curveu Ramp + 集中暴露参数兼顾网络清爽度与美术可控性，方便后续任意微调。

### 沿路径流动能量带分阶段保留基础粒子与路径变形缓存
适用条件：制作沿指定曲线路径流动、缠绕或分叉的粒子与细丝能量带。

将流程拆分为：路径/发射源缓存 → 基础粒子模拟缓存 → Path Deform（可结合 For-Each 多条曲线）变形缓存。多组不同色彩或层次的能量噪声分支保持各自独立输出和 ROP，不要强行合并为一个渲染层。调整速度时核对路径方向、curveu 范围、时间映射与 Retime 顺序。

原因与注意：先算基础形态再沿路径映射，轨迹可控性强且便于单独微调路径曲线和节奏。

### 程序化力场光丝效果：管面双尺度各向异性噪声与独立Alpha分层控制
适用条件：制作能量力场、气浪光丝、条带光幕等需要高可控性且无需流体/粒子解算器的程序化光效。

核心骨架：高细分管面/曲面 → Mountain 做小幅轮廓扰动 → 细分/多副本形成空间层次。纹理与动态：用各向异性拉伸的高低频两套噪声（如 onoise × snoise）相乘写入 Cd，制造细长断续与疏密变化；通过对噪声采样坐标 offset 沿轴向做时间偏移驱动流动。透明度与分层：用相对包围盒配合 Ramp 独立计算 Alpha 轮廓（与明暗纹理分离，便于收束边缘）；按职责拆出细密主光丝、粗亮束、暗部/柔化层分别出层，并把角色/场景加入 matte_objects 提供遮挡。具体尺寸、频率与强度按当前镜头尺度重新调节，不照搬单镜头绝对数值。

原因与注意：纯 SOP + 属性着色方案无解算开销、迭代极快，且纹理、流动与透明轮廓完全解耦。

### 角色局部粒子效果将模拟与随动变形分阶段缓存
适用条件：粒子效果需要贴附或跟随角色局部动画，且角色输入网格拓扑稳定、参考帧关系明确时。

将解算与随动变形拆成两个独立缓存阶段：第一阶段在相对静止或参考空间完成 POP 模拟并写基础模拟缓存；第二阶段用 Point Deform（三输入分别为模拟点、Timeshift 固定参考帧几何、当前帧动画几何）完成随动变形，再单独写变形后缓存。复用前务必先核对参考帧与当前帧拓扑一致性，避免变形炸点。

原因与注意：分阶段缓存把解算迭代和随动绑定解耦，调整变形或局部动画时无需重算粒子模拟。
