审查日期：2026-11-10。版本依据根目录 [uv.lock](../uv.lock)，依赖声明见 [pyproject.toml](../pyproject.toml)。下表覆盖锁文件中除 FX Agent 自身外的全部 **94 个包**，不将开发依赖或平台条件依赖省略为“未使用”。

## 证据和范围

- 本机安装的 92 个包版本均与锁文件一致；许可证与来源依据各包的发行元数据及随包许可文件。表中的“发行元数据”链接指向该确切版本的 PyPI JSON，便于复核。
- `jeepney` 与 `secretstorage` 当前平台未安装，依据对应版本 PyPI 元数据补充，未验证其安装包内许可文件。
- 范围按锁文件依赖图可达关系合并运行 / 开发 / Nuke 路径，包含 optional-dependencies 的边；实际激活还受平台、Python 版本和 extras 条件影响，不等于当前运行时全部加载。
- 许可证列保留发行元数据的表达；只有泛化 BSD、MIT style 或分类器的包明确保留原描述，不猜测细分 SPDX 标识。发行二进制前还需检查原始许可全文及嵌套组件。
- Nuke 包使用 Git 固定提交，表内源码链接指向该提交；其他仓库链接来自包元数据，精确安装输入仍以锁文件的版本、来源与哈希为准。仓库改名不改变原版权归属。
- 少数元数据未提供源码链接的包使用其说明中的项目地址补充；`py-key-value-shared` 的仓库归属另核对上游 `0.3.0` 标签的 `key-value/key-value-shared/pyproject.toml`，项目名称一致。
