# FX Agent 使用指南

FX Agent 由当前 MCP 宿主助手（Codex、Antigravity 等）负责规划、操作和视觉判断；FX Agent 提供 Houdini / Nuke / Maya 桥接工具、任务门禁和**纯文本通用经验持久化**能力。

---

## 一、核心原则：纯文本经验 vs 外部模板库

1. **纯文本通用经验（存入本仓库 `data/`）**：
   - 只保存**跨项目可复用**的个人规范（`user_rules`）、通用工艺配方（`workflow` / `compositing` / `lighting` / `render`）和排错避坑（`troubleshooting`）。
   - **禁止写入**：客户工程文件（`.hip`/`.nk`/`.ma`）、贴图、渲染序列、预览图/视频、本机盘符绝对路径（`C:/...`、`//Desktop-...`）以及单镜头写死的参数预设。
   - 所有正式入库的全局经验都会**自动同步编译**到 `data/modules/global/<software>/<module>.md`，人眼可直接审阅，并通过 Git 在多设备间轻量同步。
2. **现成工程资产（直连外部 FX Template 模板库）**：
   - 需要复用具体效果工程、HDA 或节点模板时，直接调用 `fx_search_published_templates` 检索本机运行的 [FX Template](https://github.com/Zylvia-lin/FX-Template) 桌面端，不向 `fx-agent/data` 复制或解析工程文件。

---

## 二、标准制作与任务门禁流程

为防止跳过规范读取或误改错误窗口，所有写入/渲染操作受任务门禁保护（任务管理工具传 `task_id`，受门禁 DCC/知识工具传 `fx_task_id`）：

1. **只读核对与登记任务**：
   - 检查 `fx_status`、软件连接与当前工程路径，再调用 `fx_begin_task` 登记 `software`、`project_id`、`shot_id`、`scene_path`、`endpoint`、`goal`、`acceptance`、`budget` 与 `modules`。
   - 正式制作/搭建选 `kind="production"`；同场景局部参数微调选 `kind="quick_tweak"`（仍强制端口与场景路径锁，上限 15 次编辑，可随时 `fx_update_task` 升级为 `production`）。
2. **一键聚合读取纯文本知识**：
   - 调用 `fx_prepare_task_brief(task_id=...)` 一次读取制作规范（`production_rules`）、进度上下文、模块纯文本手册（`module_knowledge`）、历史纯文本经验（`memory_matches`）及 Houdini 必需的上游指南，自动记齐门禁凭据。
   - 如需复用现成工程模板，额外调用 `fx_search_published_templates`。
3. **保存方案与受门禁制作**：
   - `production` 任务调用 `fx_set_task_plan` 提交方案及引用来源后放行；`quick_tweak` 读完简报即可局部微调。
   - 需求、输入或目标路径改变时先 `fx_update_task`；遇到未确认的不确定项用 `fx_task_question` 登记并向用户集中发问。
4. **保存、结构检查与免归档验收**：
   - 修改后保存真实工程（保留用户主版本号并追加两位助手迭代序号，如 `v02_01.hip` / `v02_01.nk`），执行 `verify_network`（Houdini/Maya）或 `find_broken_reads`（Nuke）。
   - 实际查看多时间点画面（配合 `skills/fx-visual-critique` 做结构化审片），随后直接调用 `fx_finish_task` 提交当前 `revision` 和真实 `verification_note`（**无需归档工程或截图**，`case_id` 留空）。

## 三、纯文本经验沉淀方式

- **长期制作规范**：用户在对话中提出明确要求时，调用 `fx_record_user_rule`（版本化保存规则与真实原话）。
- **排错与通用工艺**：现场解决通用问题或验证出可迁移工艺后，直接调用 `fx_submit_experience`（默认 `project_dependent=False`、`reuse_scope="global"`）：
  - `source_type="user"` 或现场实测验证的 `source_type="observed"` 直接进入 `active` 并实时刷新 `data/modules/global/<software>/<module>.md`；
  - 未实测的推测填 `source_type="inferred"`，保持在 `candidate` 候选状态；
  - 系统会自动拦截正文中残留的本机/UNC 绝对路径，确保经验跨机通用。
- **纠错轨迹与最终提纯**：过程调整用 `fx_record_feedback` 记录；用户明确确认且任务已通过 `fx_finish_task` 后，可将反馈置为 `outcome="accepted"`（免归档）并调用 `fx_finalize_learning` 提纯通用方法。
- **阶段整理（Dream）**：定期运行 `fx_dream_memory(mode="preview")` → `mode="apply"` 合并重复经验、解决冲突并刷新模块手册。

## 四、默认工具面与环境变量

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `FX_AGENT_DATA_ROOT` | `<仓库>/data` | 指定绝对数据目录路径 |
| `FX_AGENT_LOCAL_ROOT` | 同 `FX_AGENT_DATA_ROOT` | 本机 DCC 会话登记文件目录 |
| `FX_AGENT_TOOL_PROFILE` | `text_only` | 默认隐藏低频维护工具（`fx_sync_module_baselines` / `fx_refresh_module_guides` / `fx_undo_dream` / `fx_get_dream_runs`）；`production` 同时隐藏 `fx_dream_memory`；`full` 开放全部工具 |
| `FX_AGENT_HOUDINI_HIDE_GROUPS` | 空 | 可选逗号分隔隐藏 Houdini 子域工具组：`chop,cop,top,hda,usd,takes,shelf` |
| `FX_AGENT_EMBEDDING_URL` | 空 | 可选 OpenAI 兼容 embedding 接口，启用纯文本语义混合召回 |

## 五、常用规范速查

- **Houdini**：外部文件统一使用 `$HIP/...` 相对路径；File Cache 统一 `$HIP/geo/$OS/$OS.$F4.bgeo.sc`；仅在 File Cache、渲染输出等需要 `$OS` 的必要节点命名；造型与渐变参数暴露为命名参数和可编辑 Ramp，优先 VEX 精简网络。
- **Nuke**：默认单 A 查看并保留用户 B 参考；封装节点（如 `L_RealGlow`）只调暴露参数不展开内部；扭曲优先蓝宝石 Sapphire 节点；保留默认节点名，大 Backdrop 用中文标题；中央垂直总线、背景置顶、左右错层完整效果块 Read 置顶向下汇合；动态合成检查前中后三帧与峰值帧。
- **Maya**：正常无参数启动 `maya.exe`，通过共享 `.mod` 自动加载桥接；显式选择会话，不自动猜窗或自动重试超时渲染。
