# Houdini 特效造型、尺度与动态审美检查表

工具不报错、解算能跑完不等于特效好看。审片时必须查看**至少 3 个关键时间点**（起势帧、形态峰值帧、衰减尾段帧）的渲染或视口预览，逐项核查以下 6 个核心维度。

## 一、大中小三层尺度（Primary / Secondary / Tertiary）

- **问题信号**：画面只剩单一尺寸的噪点球、均匀细沙或一整块糊状体积，远看没大势、近看没细节。
- **审片标准**：
  - **大形（Primary）**：决定镜头阅读方向与力量感的大轮廓、大翻卷或主能量束；
  - **中形（Secondary）**：打断大形边缘的团块、拉丝、涡旋与次级飞溅；
  - **细形（Tertiary）**：高速边缘的细碎星点、微丝、薄烟缕与局部高频扰动（仅作点缀，不可盖过大形）。
- **节点方向**：先关掉高频细节把低分辨率大形与动态调顺，再逐层叠加不同频率/振幅的 Curl Noise、Turbulence、Shredding 或分级子发射器。

## 二、剪影可读性与正负空间（Silhouette & Negative Space）

- **问题信号**：特效糊成一坨均质亮斑，或呈机械规则圆筒/圆环/球体，完全看不到内部结构与留白。
- **审片标准**：
  - 缩成小图看剪影仍能立刻读出运动方向与形态特征；
  - 内部存在明确的**疏密对比与透空负空间**，而不是 100% 均匀填满。
- **节点方向**：用发射源遮罩（密度噪声、速度阈值、角度衰减）打破规则几何轮廓；用 `age`/`density`/`speed` 重映射 `pscale` 与 `Alpha`，形成不均匀的聚集与留白。

## 三、核心实、边缘虚的密度与亮度梯度

- **问题信号**：烟雾/火焰/能量从里到外一个亮度，或边缘像硬塑料片一样一刀切。
- **审片标准**：
  - 能量/火焰应有清晰的温度/强度分层（白热核心 → 饱和中层 → 柔暗外缘/余烟）；
  - 体积边缘随 `density` 与 `age` 自然消散，无生硬截断。
- **节点方向**：在 Shader / Volume Visualization 中拉开 `temperature`/`burn`/`density` Ramp 梯度；粒子按生命周期曲线（Ramp）控制 `Alpha` 与发射亮度，做到“渐入渐出”。

## 四、动态节奏与物理惯性（Temporal Rhythm）

- **问题信号**：所有粒子/碎块匀速直线运动、同时出生同时消失，缺乏爆发感或阻尼感。
- **审片标准**：
  - 起势有爆发加速度，中段受空气阻力/涡流弯曲拖尾，尾段减速飘散；
  - 存在速度差异与**二次运动（Secondary Motion）**（例如主光束带起周围微粒涡旋、主破碎伴随细屑和尘烟）。
- **节点方向**：检查 `POP Drag` / 空气阻力、`v` 初始随机扰动、基于速度或年龄的力场权重，以及 `life` 随机分布与 `substeps`（防止高速粒子阶梯断层）。

## 五、镜头尺度与真实世界比例感（Scale Perception）

- **问题信号**：宏大爆炸看起来像桌面打火机（翻卷太快、细节太少），或贴身能量看起来像粗大塑料管。
- **审片标准**：速度、涡旋尺度与重力加速度须匹配场景真实单位（1 unit = 1m）；大尺度现象往往更慢、细节更密，小尺度现象更迅捷锐利。

## 六、反“廉价 CG”快速红线清单

- 出现以下任一现象直接判 **Critical / Moderate 未通过**：
  1. 只在规则柱/环表面贴静态噪声，缺少真实流动与形变；
  2. 粒子高速运动时出现明显断节（发射子步不足或未插值源位置）；
  3. 体积体素出现明显块状锯齿或边界框硬切（Bounding Box 裁切）；
  4. 靠无脑拉高发光亮度掩盖造型单薄。
